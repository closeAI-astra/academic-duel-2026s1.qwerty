ACADEMIA DUEL / 配布版セキュリティ仕様

■ 個人データ
- アカウント登録、メールアドレス、電話番号、住所、位置情報、連絡先、カメラ、マイクを使用しません。
- Ver.1.11のプロフィール機能では、ユーザーが入力した表示名（ニックネーム推奨）、選択したカードID、公開戦績のみを端末保存・対戦相手へP2P共有します。
- Peer IDは氏名等ではなくランダム値のみ。ホストIDはランダム6文字招待コードから生成します。
- APIキー、パスワード、秘密鍵、認証トークンを配布HTML/JSへ埋め込みません。
- localStorageはゲームデータとプロフィール・フレンド履歴だけです。各保存領域は16KiBを上限にし、フレンド履歴は最大24件です。

■ P2P通信
- 招待コードは6文字。紛らわしい0/O/1/Iを除外した32文字から暗号学的乱数で生成します。
- 1メッセージ最大8KiB。超過時は接続を切断します。
- 10秒あたり40メッセージを超える受信は切断します。
- 受信できる型は READY / START / START_ACK / ACTION / QUESTION / ANSWER / RESOLVE / ABORT のみ。
- 各型でキー、整数範囲、カードID、デッキ枚数、ランク制限、シーズン番号を検証します。
- 相手から damage / HP / HTML / JavaScript / 任意テキストを送って結果へ直接反映するプロトコルはありません。
- 通信する主な内容はカードID、技番号、問題seed、10択の回答番号、公開プロフィール（表示名・カードID・戦績）です。戦闘結果は両端末で同じルールから再計算します。
- P2P受信値を innerHTML に入れません。対戦表示は textContent とDOM生成を使用します。
- eval() は使用しません。

■ 外部通信
- 短い招待コードの待ち合わせに PeerJS Cloud (0.peerjs.com) を使用します。
- PeerJSクライアントはバージョン1.5.5に固定し、UIを止めない非同期読み込みにしています。jsDelivrが失敗した場合のみ cdnjs → unpkg の順でフォールバックします。
- 対戦データはWebRTC DataChannelを使用します。ネットワーク条件によっては直接接続できない場合があります。
- 広告、アクセス解析、独自トラッキング、外部画像、外部フォントは使用しません。

■ ブラウザ防御
- Content-Security-Policyでスクリプト元・接続先・画像元などを制限しています。
- Referrer-Policyはno-referrerです。
- 外部から取得した自由文字列をHTMLとして描画しません。

■ 想定範囲
このゲームは仲間内の無料対戦用です。完全P2Pなので、本人がブラウザ内のJavaScriptを意図的に改変する高度なチートまでは防止しません。金銭、機密情報、本人確認、ランキング報酬を扱う用途にはサーバー権威方式への変更が必要です。


Ver.1.20 GodField mode:
- Up to 5 players in host-star P2P topology.
- Host is authoritative for HP, hands, card effects, question correctness and damage.
- Guests send only commands/answers; images and card catalog are local assets.
- Room code remains 6 characters.
- No HTML or executable code is accepted from peers.

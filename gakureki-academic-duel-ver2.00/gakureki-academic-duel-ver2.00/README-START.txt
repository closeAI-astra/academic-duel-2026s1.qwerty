学歴召喚 -academic duel- 2026S1 / Ver.1.20 起動方法（Windows）

1. ZIPを右クリック →「すべて展開」
2. 展開したフォルダ内の START-WINDOWS.bat をダブルクリック
3. ブラウザが自動で開く
4. プレイ中はローカルサーバーのPowerShell画面を閉じない

Pythonのインストールは不要です。
index.htmlを直接ダブルクリックすると、ブラウザのセキュリティ制限によりJavaScriptモジュールが動きません。

【対戦カード】
対戦専用ガチャはありません。
通常の「召喚」、水晶パック、水晶交換で獲得し、カード図鑑に登録されたカードのみデッキに使用できます。

【プロフィール】
- プロフィールタブで表示名（最大16文字）を設定できます。
- 図鑑で獲得済みの好きなカードをアイコンにできます。
- 対戦数・勝利・敗北・回答数・正解数・正解率を端末内に保存します。
- 対戦した相手の公開プロフィールはフレンド欄へ最大24件保存されます。
- 表示名は相手にP2P共有されるため、実名ではなくニックネームを推奨します。

【通信開始】
1. ホストが6文字コードを作成
2. ホストが勝利条件（1 / 3 / 4 / 5 / 6 / 7 KO）を設定
3. 相手が6文字コードで参加
4. 両者が10枚デッキを完成
5. 両者が「準備完了」を押す
6. 両者READYになればホストが自動的にSTARTを送信して対戦開始

【回答】
PC・タブレットでは10択を5列×2段で表示します。
不正解単語は復習単語ページへ自動登録されます。
